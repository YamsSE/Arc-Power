An open-source overclocking and tuning tool for Intel Arc GPUs - in the spirit of MSI Afterburner and AMD Adrenaline, built on Intel's official Graphics Control Library (IGCL). Multi-GPU support, three UI themes, live telemetry. No reverse-engineering. No third-party daemons.

Key points

Everything you need to
unlock your Arc GPU

Tuning

Power limit (W), core frequency offset (MHz), voltage offset and temperature limit (°C) - applied through Intel's documented IGCL API with read-back verification and a warranty-waiver gate. Expert controls (VRAM frequency, voltage lock, custom VF curves) appear only when your GPU reports them.

Extended range

On Alchemist, power limits up to 315 W and temperature limits up to 115 °C via a bundled 2023 IGCL runtime the kernel driver still accepts. Elevation prompt + explicit confirm required.

Fan control

Auto, curve and fixed modes with an interactive SVG curve editor - hover/drag readouts and adaptive presets (Driver Curve / Quiet / Max) derived from the driver's own curve. Read-only on boards that don't expose control.

Live telemetry

Clocks, temperatures, power from GPU energy counters, fan RPM, utilization and throttle reasons - plus FPS via DXGI frame statistics, VRAM usage, and a CPU card with RAM type and cache readouts, as readouts and rolling graphs.

Profiles & logon apply

Save, load, rename and delete named profiles, and apply one silently at every logon - elevated through a scheduled task on the installed build - with a safe default fallback.

Reversible tweaks

Registry hacks - MPO disable, HAGS and more - with one-click Enable / Disable / Revert, per-step verified writes and honest per-step reporting.

Multi-GPU

Choose which Intel Arc GPU to control on systems with several. The selection persists and drives the dashboard, tuning, telemetry, waiver and boot/tray applies.

UI themes

Three hand-tuned themes - Dark Steel, Midnight and Arctic Light - selectable in Settings and remembered across restarts, applied at boot.

Installer & packaging

Shipped as a portable EXE and a proper NSIS installer. The installed app is always elevated, so extended-range applies and silent logon applies need no prompts.

Honesty by design

Overclocking that respects
your hardware

01

Clamped ranges

Values are bounded to the device-reported minimums and maximums in both the UI and the backend. Arc Power never overrides driver-level ceilings.

02

Verified read-backs

Every apply is confirmed by reading the value back from the driver - including a delayed re-read - so a setter that "succeeds" silently never counts as applied.

03

Honest refusals

When the driver refuses, you get a truthful per-control error with a message you can act on - never a silent failure or a fake success state.
