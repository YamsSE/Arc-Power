An open-source overclocking and tuning tool for Intel Arc GPUs - in the spirit of MSI Afterburner and AMD Adrenaline, built on Intel's official Graphics Control Library (IGCL). Multi-GPU support, five UI themes, live telemetry, an in-game overlay and graphics tuning. No reverse-engineering. No third-party daemons.

Key points

Everything you need to
unlock your Arc GPU

Tuning & undervolting

Power limit (W), core frequency offset (MHz) or a frequency + voltage lock, plus Alchemist undervolting with a negative voltage offset bounded to -200 mV. Controls are applied through Intel's documented APIs with read-back verification, a warranty-waiver gate and sub-second applies. Expert controls (VRAM frequency, custom VF curves) appear only when your GPU reports them.

Extended range

On Alchemist, power limits up to 375 W and temperature limits up to 115 °C - above 252 W through the Level Zero sysman power pair (sustained + burst written together), values above the app-verified 375 W ceiling refused honestly, never clamped. Elevation prompt + explicit confirm required.

Graphics tuning

XeSS Frame Generation override (2x/3x/4x), frame synchronization, an FPS limit (30-300) and Low Latency (Off/On/On+Boost) - applied through Intel's documented 3D-feature API on the dedicated Graphics page, with an IGS-style Display view (scaling mode, quantization range, display info).

Fan control

Auto, curve and fixed modes - Fixed verified on Alchemist - with an interactive SVG curve editor, hover/drag readouts and adaptive presets (Driver Curve / Quiet / Max) derived from the driver's own curve. Read-only on boards that don't expose control.

Live telemetry

Clocks, temperatures, power from GPU energy counters, fan RPM, utilization and throttle reasons - plus FPS via ETW/PresentMon present timestamps (DXGI fallback), VRAM usage, and a CPU card with RAM type, cache readouts and CPU power on Intel and AMD, as readouts and rolling graphs.

In-game overlay

A click-through, always-on-top stats overlay - clocks, temps, FPS with 1% Low / 99% FPS percentiles and a frametime polyline. Hotkey toggle, 4-corner positioning, size, text colors, an optional background and a configurable polling rate.

Profiles & logon apply

Save, load, rename and delete named profiles, and apply one silently at every logon - elevated through a scheduled task on the installed build - with a safe default fallback.

Reversible tweaks

Registry hacks - MPO disable, HAGS and more - with one-click Enable / Disable / Revert, per-step verified writes and honest per-step reporting.

Multi-GPU

Choose which Intel Arc GPU to control on systems with several. The selection persists and drives the dashboard, tuning, telemetry, waiver and boot/tray applies.

UI themes

Five hand-tuned themes - Dark Steel, Midnight, Arctic Light, Red and Yellow - selectable in Settings and remembered across restarts, applied at boot.

Installer & packaging

Shipped as a portable EXE and a proper installer. Distributed builds request administrator access so hardware-control and logon applies have the access they need.

Honesty by design

Overclocking that respects
your hardware

01

Clamped ranges

Values are bounded to the device-reported minimums and maximums in both the UI and the backend. Arc Power never overrides driver-level ceilings.

02

Verified read-backs

Every apply is confirmed by reading the value back from the driver - including a delayed re-read - so a setter that "succeeds" silently never counts as applied.

03

Honest refusals

When the driver refuses, you get a truthful per-control error with a message you can act on - never a silent failure or a fake success state.
