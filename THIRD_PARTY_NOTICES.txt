## PawnIO (kernel driver) - the CPU MSR reader's kernel component

- Component: the PawnIO kernel driver (PawnIO.sys, version 2.2.0 - the
  official signed edition). The app does NOT bundle the driver binary: it
  opens the installed driver's device and loads a module into it. The
  official PawnIO_setup.exe (see below) installs the driver system-wide
  (its own Uninstall key + device + service - the app never creates
  services).
- License: GNU General Public License v2.0 (or later) with a special
  exception (reproduced below).
- Source: https://github.com/namazso/PawnIO
- Purpose: reading the CPU's MSRs (temperature target, package therm
  status, RAPL energy) - the HWiNFO/GPU-Z/LibreHardwareMonitor-class
  mechanism for CPU temperature + wattage, which Windows exposes in no
  user-mode API on this machine.
- The special exception: "as a special exception, the copyright holders of
  PawnIO give you permission to combine PawnIO program with free software
  programs or libraries that are released under the GNU LGPL and with
  independent modules that communicate with PawnIO solely through the
  device IO control interface. You may copy and distribute such a system
  following the terms of the GNU GPL for PawnIO and the licenses of the
  other code concerned, provided that you include the source code of that
  other code when and as the GNU GPL requires distribution of source code."
  Arc Power communicates with the driver SOLELY through the device IOCTL
  interface (IOCTL_PIO_LOAD_BINARY / IOCTL_PIO_EXECUTE_FN) and loads the
  LGPL-2.1 IntelMSR module (below) - the exact use the exception covers.
  The LibreHardwareMonitor project (MPL-2.0) is the precedent: it
  integrates PawnIO the same way.

## PawnIO.Modules - AMDFamily17.bin (the AMD MSR/SMN module)

- Component: `src/main/backend/AMDFamily17.bin`, the PawnIO module for
  AMD Zen CPUs exposing "ioctl_read_msr" / "ioctl_read_smn" /
  "ioctl_write_msr" (the SMN die temperature + the RAPL package-energy
  pair; the reader selects it on AMD vendor strings).
- License: GNU Lesser General Public License v2.1 (the same license text
  as IntelMSR.bin, reproduced in `src/main/backend/COPYING`; the module
  source header: "SPDX-License-Identifier: LGPL-2.1-or-later").
- Source: https://github.com/namazso/PawnIO.Modules - the SAME tag as
  IntelMSR.bin (0.2.10; the tag tree contains AMDFamily17.p - verified
  2026-08-11). Source file fetched from the tag: AMDFamily17.p, SHA-256
  8A1808A2E51E184F96D17362991AE900C65A1A23135A68C256EC6759E8297BB9.
- SHA-256 (the vendored module): DAE74615761B78BDF064DFB3E136252DDCC6FC727D88F14738D0E5800D427A91
- Purpose: the MSR + SMN read functions for AMD Zen (family 17h-1Ah) -
  the CPU die temperature (SMN F17H_M01H_THM_TCON_CUR_TMP) and the RAPL
